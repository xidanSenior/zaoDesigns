# Личный кабинет СНК — передача в разработку

Прототип нового дизайна «Личного кабинета 3.0» (go-personal-area-3, Vue 3 + PrimeVue + Pinia) в дизайн-системе группы. Это эталон для перевёрстки боевого SPA: переносить нужно решения (токены, компоненты, состояния, поведение), а не разметку один к одному.

Все данные вымышлены (`data/demo.js`), «живые» обновления — имитация на таймере. Места подключения API помечены `TODO` с именем store боевого ЛК.

## 1. Запуск

Стили подключаются из `../designs/`, поэтому сервер — из корня репозитория:

```
cd designSites
python -m http.server 8080
```

| Адрес | Что открыть |
|---|---|
| `/personal-area/` | вход: по телефону (код из SMS; `0000` — неверный), по карте, по логину (`seller` → продавец, `azs` → точка, иначе покупатель; пароль «ошибка» — отказ) |
| `/personal-area/purchaser/statistic.html` | стартовый экран покупателя |
| `…?demo=offline` · `?demo=stale` · `?demo=update` | баннеры «нет сети», «данные устарели», «новая версия» на любой странице |

Общие блоки (иконки, сайдбар, верхняя панель), реестры и заглушки собирает `node personal-area/tools/generate.mjs` — запускать после правки `data/*.js` или `partials/sprite.html`.

## 2. Основа

- `../designs/` — токены, шрифты, `.btn`, `.field`, `.check`, cookie-баннер, чертёжные классы. Не меняется.
- `../management/` — рабочий кабинет группы. Из него **скопированы** (не подключены) общий слой и компоненты: `styles.css` (каркас, таблица, формы, оверлеи, графики, состояния), `js/app.js`, `js/cells.js`, `js/charts.js`, `js/registry.js`, `partials/sprite.html`, генератор. Соответствие компонентов PrimeVue — `management/HANDOFF.md`, §4; UI kit со всеми состояниями — `management/ui-kit.html`.
- Из `app.js` убран переключатель организации management: в ЛК контрагент — это сам пользователь (у продавца — выбор контрагента внутри раздела, как `codA`).

## 4. Новые компоненты ЛК

Стили — конец `styles.css` (раздел «Личный кабинет»), общие куски разметки — `js/pa.js`. Новых цветов нет: вид топлива = `--series-1…4` (АИ-92, АИ-95, ДТ, газ — закреплены за топливом во всех графиках и метках), статусы = `--st-*`.

| Компонент | Класс / функция | PrimeVue / боевой ЛК | Правила |
|---|---|---|---|
| Контекст в верхней панели | `.ctx` | — | организация, карта или точка, с которой работает пользователь; скрыт < 1280 px |
| Лицевая сторона карты | `.fcard`, `SNC.pa.face()` | свой компонент | номер — моно, табличные цифры; блокированная — серая |
| Кошелёк с лимитом | `.wallet`, `SNC.pa.wallet()` | `ProgressBar` | шкала показывает **остаток**; < 10 % — `--st-warn` и подпись «Осталось меньше 10%» |
| Мини-шкала в таблице | `.lim`, `SNC.pa.lim()` | шаблон колонки `DataTable` | «остаток / лимит · топливо» + шкала 4 px |
| Баланс и запас | `.bal`, `.runway` | `Card` + своя шкала | отметка — сигнальный лимит (`--accent`), прогноз дней; кнопка «Выписать счёт» с рекомендуемой суммой |
| QR-код оплаты | `.qr`, `#dlg-qr` | `Dialog` + qrButton | 60 с, кольцо-таймер, по истечении — «Обновить»; объявление за 10 с |
| Карта-схема точек | `.stn-layout`, `.map__pt` | замена — Яндекс Карты | метки в экранных пикселях при любом масштабе; выбор синхронизирован со списком; клавиатура — Enter/Space |
| Фильтр-чип | `.fchip[aria-pressed]` | `ToggleButton` | цветной квадрат = топливо |
| Сканер купонов | `.scan`, `.coupon-tkt` | useBarcodeScanner | линия сканирования отключается при reduced-motion |
| «Откуда → куда» | `.xfer` | — | итоговый шаг мастеров переноса |
| Выбор карты в мастере | `.pick-card` | `Listbox` / `DataTable` selection | радио или чекбокс + мини-шкала |
| Предпросмотр счёта | `.inv-sheet` | pdfFile | сумма прописью, НДС 20 % |
| Причины блокировки | `.reasons` | `RadioButton` | «Временно» обратимо, «Утеряна» — чёрный список |

Поведение: блокировка и сдача карт — подтверждение «Что произойдёт» → тост с «Вернуть» (для обратимых); плитки реестра карт — фильтр, повторный клик снимает; заправки по таймеру уменьшают остатки, строка подсвечивается, при переходе через 10 % — тост с действием «Изменить лимит».

## 5. Данные

`data/demo.js` — детерминированная генерация (seed), одинаковая для генератора и браузера: 36 карт в 4 подразделениях, 23 точки по Томской области, 160 транзакций за 3 месяца, итоги по месяцам 2026, договоры, платежи, документы, контрагенты и операции продавца, смены точки. Реальные организации, люди, номера и адреса не используются.

## 6. Что проверено

- Все 33 страницы открываются без ошибок JS (headless Chrome).
- Нет горизонтальной прокрутки страницы на 390 px (таблицы прокручиваются внутри себя).
- reduced-motion: схема входа, графики, шкалы, сканер — сразу в финальном состоянии.
